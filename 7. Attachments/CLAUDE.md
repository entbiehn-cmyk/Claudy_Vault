# 7. Attachments/ — 첨부 파일

## 목적과 역할
이미지, PDF, 오디오, 엑셀 등 **Markdown이 아닌 모든 파일**을 한곳에 모아 노트 폴더를 깔끔하게 유지합니다.

## 들어가는 노트
- 노트에 삽입되는 이미지·스크린샷, PDF, 첨부 문서, 오디오 등
- Markdown 노트는 두지 않습니다 (이 CLAUDE.md 제외)

## 작업 방식과 규칙
- Obsidian 설정 → 파일 및 링크 → "새 첨부 파일의 기본 위치"를 이 폴더로 지정해 사용합니다.
- 파일명은 의미 있게 바꿉니다: `YYYY-MM-DD 설명.확장자` (예: `2026-10-16 회의 화이트보드.png`). `Pasted image 2026...` 같은 기본 이름은 정리합니다.
- 파일 수가 많아지면 유형별 하위 폴더(`images/`, `pdf/`, `audio/`)로 나눌 수 있습니다.
- 첨부는 노트에서 `![[파일명]]`으로 임베드합니다. 어떤 노트에서도 참조되지 않는 파일은 사용자 확인 후 정리합니다.
- 파일 이동·이름 변경은 링크가 깨지지 않도록 Obsidian 또는 obsidian-vault MCP를 통해 합니다.
