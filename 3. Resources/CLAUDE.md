# 3. Resources/ — 참고 자료

## 목적과 역할
관심 주제별로 **나중에 꺼내 쓸 참고 자료**를 보관합니다. PARA의 "R"입니다. 내 생각으로 소화되기 전의 정보 창고입니다.

## 들어가는 노트
- 주제별 하위 폴더: 예) `3. Resources/개발/`, `3. Resources/요리/`
- 체크리스트, 매뉴얼, 설정 방법, 링크 모음, 스니펫, 레퍼런스 표 등 "찾아보는" 용도의 자료

## 작업 방식과 규칙
- frontmatter:
  ```yaml
  type: resource
  topic: 주제
  source: URL 또는 출처
  ```
- **Literature 노트와의 구분:** 책·글·강의를 읽고 *내 말로 요약·분석*한 것은 `5. Zettelkasten/10. Literature/`로 갑니다. Resources는 그대로 참조하는 실용 자료입니다.
- 원문을 통째로 붙여넣기보다 출처 링크 + 핵심 발췌로 짧게 유지합니다.
- 오래되어 쓸모없어진 자료는 `4. Archive/3. Resources/`로 옮깁니다.
