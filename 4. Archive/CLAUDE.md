# 4. Archive/ — 완료된 항목

## 목적과 역할
**더 이상 활성 상태가 아닌** Projects·Areas·Resources를 보관하는 냉동고입니다. 작업 공간을 가볍게 유지하면서도 기록은 잃지 않기 위해 존재합니다.

## 들어가는 노트
- 완료·중단된 프로젝트 폴더
- 더 이상 관리하지 않는 영역
- 쓸모가 다한 참고 자료

## 작업 방식과 규칙
- 원래 위치를 알 수 있도록 하위 폴더를 원래 이름 그대로 둡니다: `4. Archive/1. Projects/`, `4. Archive/2. Areas/`, `4. Archive/3. Resources/`
- 옮길 때 폴더 구조와 파일명을 그대로 유지하고, frontmatter에 `archived: YYYY-MM-DD`를 추가합니다.
- 이동은 반드시 링크가 갱신되는 방식(Obsidian 이동 기능 또는 obsidian-vault MCP의 move 도구)으로 합니다.
- 여기서는 새 노트를 작성하지 않습니다. 다시 활성화되면 원래 위치로 되돌립니다.
- **5. Zettelkasten 노트는 아카이브하지 않습니다.** 영구 지식은 완료 개념이 없습니다.
- 삭제는 사용자가 명시적으로 요청할 때만 합니다.
