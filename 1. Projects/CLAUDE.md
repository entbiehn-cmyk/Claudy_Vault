# 1. Projects/ — 프로젝트 작업대

## 목적과 역할
**마감일과 명확한 완료 조건이 있는** 진행 중인 작업을 모아두는 곳입니다. PARA의 "P"이며, 지금 실제로 손을 움직이고 있는 일의 작업대입니다.

## 들어가는 노트
- 프로젝트 하나당 하위 폴더 하나: `1. Projects/프로젝트명/`
- 폴더 안에는 대표 노트 `프로젝트명.md`(목표·마감일·할 일)와 회의록, 초안, 작업 메모 등
- 예: "2026 블로그 리뉴얼", "11월 발표 자료 준비"

## 작업 방식과 규칙
- 대표 노트 frontmatter에 반드시 다음을 둡니다:
  ```yaml
  type: project
  status: active      # active | on-hold | done
  deadline: YYYY-MM-DD
  area: "[[관련 Area]]"
  ```
- 마감일이나 완료 조건이 없다면 프로젝트가 아닙니다 → `2. Areas/`로 보냅니다.
- 프로젝트 중 얻은 **재사용 가능한 통찰**은 여기 묻어두지 말고 `5. Zettelkasten/20. Permanent/`에 영구 노트로 만들고 링크로 연결합니다. 작업대는 언젠가 치워지지만 지식은 남아야 합니다.
- 완료되거나 중단되면 폴더째 `4. Archive/1. Projects/`로 이동하고 `status: done`으로 바꿉니다. 삭제하지 않습니다.
- 첨부 파일은 이 폴더가 아니라 `7. Attachments/`에 둡니다.
- 새 프로젝트는 `6. Templates/TPL - Project.md`로 시작합니다.
