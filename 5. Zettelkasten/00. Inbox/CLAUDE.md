# 5. Zettelkasten/00. Inbox/ — 빠른 메모

## 목적과 역할
**생각을 잃지 않기 위해 일단 던져두는 곳**입니다. 정리·분류 고민 없이 빠르게 캡처하는 것이 유일한 목표입니다. 이곳은 머무는 곳이 아니라 거쳐 가는 곳입니다.

## 들어가는 노트
- 떠오른 아이디어, 질문, 한 줄 메모, 나중에 볼 링크, 대화 중 들은 말 (Fleeting notes)
- 형식·완성도는 상관없음

## 작업 방식과 규칙
- 파일명: `YYYY-MM-DD 짧은 제목.md`
- frontmatter는 최소한으로:
  ```yaml
  type: fleeting
  created: YYYY-MM-DD
  ```
- **정기적으로 비웁니다**(권장: 주 1회). 각 메모마다 다음 중 하나를 결정합니다:
  - 원천 자료 정리가 필요 → `10. Literature/`
  - 독립된 아이디어로 발전 가능 → `20. Permanent/`에 새 영구 노트 작성
  - 할 일·프로젝트 관련 → `1. Projects/` 또는 `2. Areas/`
  - 가치 없음 → 삭제 (사용자 확인 후)
- 2주 이상 처리되지 않은 메모가 쌓이면 사용자에게 정리를 제안합니다.
