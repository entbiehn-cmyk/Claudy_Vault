# 5. Zettelkasten/20. Permanent/ — 영구 지식

## 목적과 역할
Zettelkasten의 핵심입니다. **하나의 아이디어를 내 말로, 맥락 없이도 이해되게** 쓴 노트들이 서로 연결되어 지식 네트워크를 이룹니다. 이 노트들은 프로젝트가 끝나도 남습니다.

## 들어가는 노트
- 원자적 아이디어 하나를 담은 영구 노트 (Permanent notes)
- 여러 영구 노트를 묶는 MOC(Map of Content) 노트

## 작업 방식과 규칙
- **원자성:** 노트 하나 = 아이디어 하나. 두 가지를 말하고 있다면 나눕니다.
- **제목은 주장으로:** 주제어가 아니라 아이디어 자체를 문장으로 씁니다.
  - ❌ `습관.md` → ✅ `습관은 의지보다 환경 설계로 만들어진다.md`
- **자기완결성:** 원문이나 다른 노트를 보지 않아도 이해되게 씁니다.
- **연결 필수:** 새 노트는 기존 영구 노트와 최소 1개 이상 링크합니다. 고립된 노트를 만들지 않습니다. 출처가 있으면 해당 Literature 노트도 링크합니다.
- frontmatter:
  ```yaml
  type: permanent
  created: YYYY-MM-DD
  tags: []
  source: "[[@저자 - 제목]]"   # 있을 때만
  ```
- MOC 노트는 파일명 `MOC - 주제.md`, `type: moc`로 만들고 관련 영구 노트를 구조화해 나열합니다.
- 노트는 계속 다듬어 나갑니다. 삭제나 아카이브 대신 수정·분할·병합합니다.
